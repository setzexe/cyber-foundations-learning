# SQL 

SQL (Structured Query Language) is the main interface for interacting with relational databases. It defines how applications read, modify, and verify inputted data to stored data. 

SQL is critical in cybersecurity. SQL injection is a serious risk, as it can compromise essential data, which becomes lost forever without a backup. SQL injection, along with other attacks like overly permissive queries, remain one of the most common vulnerabilities in real world systems.

This section focuses both on basic utility & learning on the language, as well as SQL from a security standpoint.

## Relational Databases

This is the concept that databases relate to one another, similar to Microsoft Excel sheets. You might have a table of ID's. These would relate to a table of car's. Two columns, fixed rows, relational database.
