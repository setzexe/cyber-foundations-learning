# Databases

Databases are systems designed to store, retrieve, and manage structured data reliably at scale. They sit behind authentication and business logic. Websites and large-scale-servers will store credentials and user data here.

Due to databases being so vital, they also create huge risks in cybersecurity. Malicious queries that bypass validation can lead directly to data leakage, system takeover, or account compromisation. This folder focuses on understanding query behavior, misuse leading to security failures, etc.
