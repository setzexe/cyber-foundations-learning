# CSS

CSS is responsible for the visual presentation of web content. Layouts, styling, visibility, etc. It does not control application logic BUT can influence how users interact with a website. 

In cybersecurity, CSS is relevant due to its ability to cause visual deception and user manipulation. CSS that is edited can direct to malicious links and could hide important elements, all without the use of Java. 

Unlike Java & HTML, this will only be teaching basic understanding. Enough to understand it and relevance to cybersecurity, but not to be profecient in frontend design.
