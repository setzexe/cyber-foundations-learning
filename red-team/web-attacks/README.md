# Web Attacks

Web attacks target application layer logic that may be exposed in HTTP based services. These include various methods to try to manipulate/access data such as backend services (databases) or frontend (XSS injection, HTML injection, etc). 

The web is extremely popular, making web attacks some of the most frequent type of attacks in cybersecurity. Understanding how attackers manipulate requests, bypass validation, and abuse application logic is essential for identifying vulnerabilities and tightening security.
