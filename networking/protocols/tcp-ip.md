# TCP/IP

As we learned already, IP (internet protocol) works as the addressing system of the internet. It is how clients and servers know who they delivering packets to. When packets are being sent, lost packets or errors aren't checked. TCP (Transmission Control Protocol) is what handles this "fixing". IP makes sure the packets get there, TCP makes sure it arrived correctly.

TCP/IP (or known as the Internet Protocol suite) is the protocol suite that acts as the medium for computer-to-computer communication. TCP will break down data into packets. IP locates where the data should go to, and TCP handles the data. Recompilation, verification, etc is handled by TCP. It also keeps the connection going until all the data is sent.

IP is connectionless. Information is sent and there is no confirmation from the recipient confirming data was sent. This is why it works with TCP. TCP maintains this connection and ensures easy communication from both sides.

IP primarily relies on IPv4 addresses. While IPv6 was created and is seeking for more use, the current scape of the internet relies on tools that focus on IPv4.
